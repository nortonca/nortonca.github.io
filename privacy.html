Connected Agent System: Privacy Policy

Last updated: November 23, 2026

Connected Agent System is a private tool used by one person, its owner, to let their own computers work with their own Google account (Gmail, Calendar, Drive, Docs and Sheets). It is not offered to the public, and no one else can sign in to it.

What data it uses

When the owner signs in, the tool receives a Google access token for the owner's account. It uses that token only to read and change the owner's own Google data when the owner asks it to.

Where data is kept

Tokens and any Google data the tool reads stay on the owner's own computers. Nothing is sent to the developer, sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computers removes all stored access.
